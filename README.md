# AMI Weld Programme Studio

Mobile-first, browser-local draft calculator based on the supplied AMI Weld Program Calculator v8 OSC workbook. Standard orbital and oscillation modes, four or six levels, live calculations, local weld log, CSV exports and print-to-PDF.

## Run
Open index.html in a browser. No dependencies or server required. For offline caching and installation use HTTPS hosting.

## GitHub Pages
Create a repository, upload the contents of this folder to its main branch, then configure Settings > Pages > Deploy from a branch > main > / (root). Check access and confidentiality before publishing any company-related calculation logic. GitHub Pages visibility depends on account and repository settings. The app stores job inputs locally in each browser and does not transmit them, but the published source itself may be accessible to others.

On iPhone, open the hosted app in Safari and use Share > Add to Home Screen. On Android, use the browser's install/add-to-home-screen option.

## Validation
This is a draft engineering calculator, not a qualified weld procedure, nor a native AMI machine upload file. Verify formulas, WPS limits, calibration, STEP travel, actual welding speed, program values and weld trials before production. See in-app calculation notes for source workbook inconsistencies.
